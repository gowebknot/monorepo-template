# Minimal portable skill

```markdown
---
name: review-api
description: Review API changes for compatibility, validation, and error-handling problems. Use when a user asks to review or audit an API change.
---

# Review API Changes

1. Inspect the changed API contract and its callers.
2. Check compatibility, input validation, authorization, and error behavior.
3. Report findings by severity with concrete file references.
```

The containing `review-api/` directory must also include `scripts/`,
`references/`, `assets/`, `templates/`, and `examples/`.
