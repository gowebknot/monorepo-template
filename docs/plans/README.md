# Future Plans

This folder contains future feature plans, improvement ideas, and architectural proposals that are
not yet active implementation work.

Use a separate dated checklist under `docs/checklists/` when a plan is approved for implementation.
Link the plan and checklist to each other when both exist.

Suggested plan statuses:

- `idea`: captured for later consideration
- `planned`: scope and approach are defined
- `in-progress`: implementation has started
- `completed`: implementation and validation are finished

Plans should explain the problem, proposed outcome, scope, open decisions, and success criteria.
Keep implementation-specific validation and task progress in the corresponding checklist.
